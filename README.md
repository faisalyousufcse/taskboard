# taskboard

Kanban-style project tracker built with Next.js and PostgreSQL.

> Status: planned. This repository holds the project outline, and the code is on its way.

## Overview

A self-hostable project tracker with boards, cards and teams, built as a reference full-stack TypeScript application.

## Planned features

- Boards, columns and drag-and-drop cards
- Teams, roles and invitations
- Activity history for every card
- REST API with typed client

## Tech stack

TypeScript, Next.js, PostgreSQL, Prisma
